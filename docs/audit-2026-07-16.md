# Full audit — 2026-07-16 (game + engine)

Scope: quality, visuals, performance, across this repo and `../engine`.
Method: both checkouts verified current with origin **first** (the
stale-checkout audit trap is real and documented), then three parallel
deep passes (game code, engine, content/assets), every finding verified
against source with file:line evidence before it was written down. This
file is the durable record; the actionable items live as PRs and
registry tickets, linked below.

## The standing decision that shaped the follow-ups

**No performance win may cost visual quality.** The dev box (Radeon
760M) running ~26–28 fps at shipped defaults is *accepted*; real
hardware is the target. Explicitly rejected as "improvements": shipping
lower default output/render scale, texture downres, terrain decimation,
grass density cuts, disabling GI/effects. Perf work must be
quality-neutral by construction (caching, deduplication, culling of
invisible work, algorithmic fixes) and — per the twice-earned rule from
the perf rounds — verified with screenshots when it touches anything
visible. EN-053/EN-060 carry this constraint verbatim.

(For completeness: the quality-*neutral* lever that exists and is the
player's to pull is `DISPLAY RESOLUTION` in settings — EN-046 measured
0.8 → locked 60 fps on this box. It stays a player choice, not a
default.)

## What was fixed immediately (shooter PRs #28–#30)

**PR #28 — audit quick wins.**
- Four functions imported but never exported (`countAlive`,
  `spawnEnemy`, `despawnAllEnemies`, `damageEnemy`) — called every
  frame across modules; only Perry's indifference to export semantics
  made it work.
- `dt` clamped to 100 ms — a stalled frame (see EN-054) stepped the
  Euler integrators far enough to carry a charging dragoon over a
  wall's repulsion ring.
- PERFTEST's `perfTB` was never assigned — phase B/C attribution in the
  perf instrument of record was silently wrong.
- Score table knew 5 of 7 kinds (both ranged upgrade kinds scored below
  a mantis); `commitRun`/`bestScore` hardcoded arena slot 0 at 5 sites.
- Finding-11 hygiene: one `playerPosition()` FFI read per frame (was
  7–8, worst case in the per-projectile loop), hoisted per-tree /
  per-mesh draw objects, diag strings built only where drawn, ~45
  stranded imports removed (each verified unused by occurrence count).
- 261 committed mojibake sequences + one BOM repaired across 5 source
  files (PowerShell round-trip damage; comment-only).
- `perry-quirks.md` no longer claims runtime world loading is
  impossible and points at a deleted tool.

**PR #29 — repo weight + licensing (~220 MB out of the tree).**
- **ShareTextures compliance**: `robinia/` + `platanus/` (66 MB) were
  committed, but ShareTextures grants CC0 *only for direct downloads*
  and forbids redistribution in collections and automated downloads.
  Untracked + gitignored + documented in
  `assets/textures/external/SOURCES.md` (manual re-download; the baked
  leaf cards in `prop_tree2/3.glb` are legitimate derivatives).
- `assets/music/src` (94 MB of Suno masters, tool-input only)
  untracked. **They are not re-derivable — archive them outside the
  repo.**
- Music ships as OGG q8: 33.9 → 4.9 MB (+ the never-taken fallback beds
  23.4 → 3.2 MB, contract intact). New `tools/encode-music.ts` closes
  the mastering pipeline; boot logs the three bed handles so a decode
  failure can never ship silently.
- Orphans deleted: `arena.glb` + `convert-arena.ts`,
  `building_wall/floor.glb` (superseded by the baked material shell) —
  and `build-props.ts` stops emitting the latter. The small prop GLBs
  (barrel/flower/grasstuft) deliberately stay: authoring palette for
  the second arena.
- DXC DLLs gitignored + documented (they enable `ray_query=true` on
  DX12 — see EN-058 for the deployment story).

**PR #30 — the adv dragoon exists visually now.**
`enemy_adv_dragoon.glb` was byte-identical to `enemy_dragoon.glb`
(upstream level3 has no adv art), so the game's only ranged heavy was
indistinguishable from the melee heavy. Both kinds load one GLB
(−4.9 MB); a new per-kind `KIND_TINTO` gives the adv a violet shift
that survives the hit flash and the corpse draws. Tune the exact value
when an adv-dragoon wave is next played by a human.

## What remains, honestly (content > rendering)

The renderer is past diminishing returns; the quality ceiling is
content and was before this audit:

1. **One playable arena** (SH-040). Everything a second arena needs
   exists — including the terrain-paint pipeline, which ships complete
   with **zero painted cells** in arena_02. This is authoring work.
2. **Enemies can't climb the stairs** (SH-051 🟡) — upstairs is a
   camping spot until the nav grid lands; `nav.ts` has the groundwork.
3. **Rect-and-text UI** everywhere (deliberate, pending EN-030) and
   **synthesised SFX stand-ins** (ASSET-TODO A1/A2/A3/A5/A6, T2/T3 —
   the blood decal is the one most needing real art).
4. SH-043: localization table + rebindable keys (❌, and EN-059 gates
   the former); SH-048: crouch capsule not resized.
